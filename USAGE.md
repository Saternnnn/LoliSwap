# Инструкция по использованию LoliSwap GUI

LoliSwap GUI — это программа для переключения между локальными профилями Loliland Launcher. Она работает с локальными файлами лаунчера и может опционально хранить логин/пароль профиля в защищённом хранилище Windows DPAPI для автологина.

## Основной принцип работы

Для каждого аккаунта создаётся отдельный локальный профиль.

Пример:

```text
main — основной аккаунт
alt — второй аккаунт
```

После сохранения профилей можно выбирать нужный профиль в программе и нажимать **Переключиться**.

## Перед началом

Перед сохранением или переключением профиля Loliland Launcher должен быть полностью закрыт.

Если лаунчер открыт, часть файлов может быть заблокирована. В этом случае профиль может сохраниться неполностью или переключение может завершиться ошибкой.

## Первый запуск

Запускается файл:

```text
LoliSwap.exe
```

Если используется запуск из исходного кода:

```bash
python loliswap_app.py
```

После запуска откроется окно LoliSwap GUI.

## Выбор папки Loliland

В поле **Папка Loliland** должен быть указан путь к локальной папке данных Loliland Launcher.

Для автоматического поиска используется кнопка:

```text
Найти папку
```

Если программа нашла одну подходящую папку, она выберет её автоматически.

Если найдено несколько вариантов, нужную папку можно выбрать вручную через кнопку выбора папки.

## Выбор файла лаунчера

Поле **Файл лаунчера** используется для выбора `.exe` файла Loliland Launcher.

Этот пункт нужен только в том случае, если требуется автоматический запуск лаунчера или автологин после переключения профиля.

Если автоматический запуск или автологин не нужен, поле можно оставить пустым.

## Сохранение логина и пароля

Для каждого профиля можно сохранить отдельный логин и пароль:

1. В поле **Профиль** выбрать или ввести имя профиля.
2. Ввести **Логин**.
3. Ввести **Пароль**.
4. Нажать:

```text
Сохранить логин/пароль
```

Пароль шифруется через Windows DPAPI и привязывается к текущему пользователю Windows. Если нужно заменить пароль, введите новый пароль и снова нажмите **Сохранить логин/пароль**.

## Сохранение первого профиля

1. Открыть Loliland Launcher.
2. Войти в первый аккаунт.
3. Полностью закрыть Loliland Launcher.
4. Открыть LoliSwap GUI.
5. В поле **Профиль** ввести имя профиля, например:

```text
main
```

6. Нажать:

```text
Сохранить профиль
```

После этого программа сохранит текущее состояние лаунчера как профиль `main`.

## Сохранение второго профиля

1. Открыть Loliland Launcher.
2. Выйти из первого аккаунта.
3. Войти во второй аккаунт.
4. Полностью закрыть Loliland Launcher.
5. В LoliSwap GUI в поле **Профиль** ввести имя второго профиля, например:

```text
alt
```

6. Нажать:

```text
Сохранить профиль
```

После этого в программе будет два профиля:

```text
main
alt
```

## Переключение между профилями

Для переключения:

1. Выбрать нужный профиль в поле **Профиль**.
2. Нажать:

```text
Переключиться
```

Программа восстановит локальные файлы выбранного профиля.

После завершения операции можно открыть Loliland Launcher.

## Автоматический запуск лаунчера после переключения

Чтобы программа запускала лаунчер сама:

1. В поле **Файл лаунчера** выбрать `.exe` файл Loliland Launcher.
2. Включить опцию:

```text
Запускать лаунчер после переключения
```

3. Выбрать профиль.
4. Нажать:

```text
Переключиться
```

После переключения LoliSwap автоматически запустит выбранный `.exe` файл.

## Автологин после переключения

Чтобы LoliSwap сам ввёл логин и пароль:

1. Сохранить логин и пароль для нужного профиля.
2. В поле **Файл лаунчера** выбрать `.exe` файл Loliland Launcher.
3. Включить опцию:

```text
Автологин после запуска
```

4. Выставить задержку в секундах. Обычно подходит 5-8 секунд.
5. Выбрать профиль.
6. Нажать:

```text
Переключиться
```

Программа запустит лаунчер, подождёт заданное время и отправит в активное окно:

```text
логин → Tab → пароль → Enter
```

Во время автологина нельзя переключать фокус на другое окно, иначе логин или пароль могут попасть не туда.

## Удаление профиля

Для удаления сохранённого профиля:

1. Выбрать профиль в списке.
2. Нажать:

```text
Удалить профиль
```

Удаление профиля удаляет только локальную копию в LoliSwap. Сам аккаунт Loliland не удаляется.

## Обновление списка профилей

Если профиль был добавлен или удалён, список можно обновить кнопкой:

```text
Обновить список
```

## Открытие папки профилей

Кнопка:

```text
Открыть папку профилей
```

открывает локальную папку, где LoliSwap хранит сохранённые профили.

Обычно это:

```text
C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\Documents\LoliSwap
```

## Режим полного копирования

По умолчанию LoliSwap не копирует временные и тяжёлые папки:

```text
cache
logs
temp
crash-reports
downloads
updates
```

Это ускоряет сохранение и переключение профилей.

Опция **Полное копирование** включает копирование всех файлов без исключений.

Обычно эта опция не нужна. Её стоит использовать только в том случае, если обычное переключение работает некорректно.

## Лог операций

В нижней части окна находится блок **Лог**.

В нём отображаются:

- выбранные пути;
- ход сохранения профиля;
- ход переключения профиля;
- ошибки доступа;
- сообщения о завершении операции.

Если что-то не работает, сначала следует посмотреть текст в логе.

## Где хранятся профили

LoliSwap хранит профили локально:

```text
C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\Documents\LoliSwap
```

Пример структуры:

```text
LoliSwap
├── config.json
└── profiles
    ├── main
    └── alt
```

`config.json` хранит настройки программы.

Папка `profiles` хранит сохранённые профили.

## Важное предупреждение

Папку:

```text
Documents\LoliSwap
```

нельзя публиковать, отправлять другим людям или загружать в GitHub.

В ней могут быть локальные данные сессии.

Если в приложении сохранены логины и пароли, `config.json` также содержит зашифрованные DPAPI-данные. Этот файл всё равно нельзя публиковать или отправлять другим людям.

## Возможные проблемы

### Программа не нашла папку Loliland

Решение:

- выбрать папку вручную;
- убедиться, что Loliland Launcher хотя бы один раз запускался на этом компьютере.

### Ошибка доступа к файлам

Причина обычно в том, что Loliland Launcher всё ещё открыт.

Решение:

1. Закрыть Loliland Launcher.
2. Открыть диспетчер задач.
3. Завершить оставшиеся процессы лаунчера, если они есть.
4. Повторить операцию.

### После переключения лаунчер снова просит пароль

Это возможно, если лаунчер хранит часть сессии в другом месте или проверяет её на сервере.

LoliSwap не обходит авторизацию и не гарантирует вход без повторного ввода пароля.

Решение:

- сохранить логин и пароль для профиля;
- включить **Автологин после запуска**;
- увеличить задержку автологина, если лаунчер открывается дольше.

### Профиль не появился в списке

Решение:

- нажать **Обновить список**;
- проверить лог;
- убедиться, что профиль был успешно сохранён.

### Переключение работает, но запускается не тот лаунчер

Решение:

- заново выбрать правильный `.exe` файл в поле **Файл лаунчера**;
- повторить переключение с включённой опцией автоматического запуска.

## Краткий сценарий использования

```text
1. Открыть Loliland Launcher.
2. Войти в первый аккаунт.
3. Закрыть лаунчер.
4. В LoliSwap сохранить профиль main.
5. Открыть Loliland Launcher.
6. Войти во второй аккаунт.
7. Закрыть лаунчер.
8. В LoliSwap сохранить профиль alt.
9. Для каждого профиля сохранить логин и пароль, если нужен автологин.
10. Для смены аккаунта выбрать main или alt и нажать Переключиться.
```
